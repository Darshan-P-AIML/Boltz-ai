
# ⚡ BOLTZ AI
### Redefining Event Discovery for Gen Z

BOLTZ AI is an AI-powered event discovery platform
designed to help Gen Z discover events, hackathons,
workshops, and experiences based on their interests.

## ✨ Features
- Personalized event recommendations
- Hackathon discovery
- Interest-based event matching
- Event search and filtering
- Modern and responsive interface

## 🛠️ Tech Stack
- React
- Vite
- JavaScript
- Node.js
- SQLite
